# 中国大陆电视直播公开来源调研

> 调研日期：2026-08-02。本文只评估公开可见的来源与技术可行性，不构成版权或法律意见，也不把“URL 可访问”解释为“获准再分发”。

## 结论先行

1. **不存在一个同时满足“官方、长期固定 URL、全国公网、允许第三方公开聚合”的央视/全国卫视 M3U。** 官方站点适合最终用户直接观看；其播放地址多由网页运行时取得，并可能携带签名、Cookie、Referer、设备参数或地域/赛事版权限制。
2. **公共 M3U 仓库只能作为候选发现源，不能作为质量与授权来源。** 它们常混合官方 CDN、校园网、运营商 IPTV、个人反代和不明中转。后几类即使探测时可播，也可能只在某省/某运营商网络有效，或随时关闭。
3. 要提升“流畅度和质量”，应把当前工程改为“多源候选 + 从部署地实测 + 分运营商/IPv4/IPv6 输出 + 自动降级”，而不是继续扩大未经验证的频道数量。全国公网主订阅只纳入能够持续通过 HLS 媒体段、分辨率、码率和连续播放测试的候选；运营商/校园网候选放入独立订阅。
4. **合规上最稳妥的产品形态是官方直播入口索引或仅在用户本机动态解析、播放，不把解析出的临时媒体 URL 提交到公开仓库。** 央视网明确禁止未经许可的再发布、播放和再发行；总台另有声明，未经书面授权不得通过互联网、IPTV、互联网电视或应用软件直播/延播/点播其版权资产（[央视网服务协议](https://app.cctv.com/special/2022/ounicom/privacy.html)、[总台版权资产保护声明](https://1118.cctv.com/2019/09/26/ARTIBhTWd4pZoAqrLPoDCubA190926.shtml)）。

### 官方来源的共同技术判断

- **协议**：网页电视直播以 HLS (`.m3u8` + TS/fMP4) 为主，也可能使用 DASH、FLV 或 WebRTC；M3U 文件中的外层 URL 成功并不等于媒体分片可连续下载。
- **临时鉴权**：`token`、`auth_key`、`txSecret`/`txTime`、Cookie、Referer、User-Agent 和设备标识都可能参与鉴权。带过期时间的 URL 不应进入长期订阅。
- **地域限制**：省级 CDN 可能全国可达但跨省质量较差；体育/电影节目还会临时黑屏或切换版权提示。一次 HTTP 200 不能证明全天候可用。
- **更新频率**：官方页面按业务需要更新，没有面向第三方订阅的 SLA。建议入口每日检查，媒体候选至少每 6 小时复测；赛事频道开播前另行复测。
- **法律边界**：官方“可在线看”不等于允许第三方重新聚合、公开传播或代理转发。央视网协议明确仅允许私人、非商业使用，并限制再发布、播放、镜像和反向工程（[协议全文](https://www.cctv.com/special/guanyunew/fuwuxieyi/index.shtml)）。

## 全国公网、运营商专网与不可取来源的判定

| 类型 | 典型特征 | 默认处理 |
|---|---|---|
| 全国公网官方 CDN | HTTPS；域名归属电视台/官方平台或其明确 CDN；无私有 IP；多运营商探测可达；媒体段连续 | 最高优先级，但仍需授权审查和节目级限制检测 |
| 全国公网第三方 CDN/中转 | 个人域名、云服务器 IP、`live.php?id=`、反代跳转 | 低权重；只有可追溯授权、稳定 HTTPS、多点测速均通过时才考虑，默认不公开发布 |
| 省内/运营商 IPTV | `PLTV/...`、`rrs*.gmcc.net`、`dbiptv.*.chinamobile.com`、裸 IPv6、特定电信/联通/移动域名 | 单列 `operator/地区-运营商.m3u8`，绝不标为全国公网 |
| 组播/RTP/UDP 网关 | `rtp://239.*`、`udp://239.*` 或个人 HTTP 网关转发组播 | 只适合对应局域网/专网；公网个人网关有稳定性与授权风险，默认剔除 |
| 校园网/机构内网出口 | `.edu.cn` 或单位 IPTV 主机 | 仅限获得许可且在该网络内使用；不进入公共订阅 |
| 临时签名 URL | `token`、`auth_key`、`txSecret`、`txTime` 等含时效参数 | 不持久化；若有合法 API 授权则运行时获取，否则剔除 |
| 不明“4K/8K” | 标签声称 4K，但无 3840×2160 探测结果，或由个人 PHP/IP 中转 | 按实测分辨率重新标记；未通过连续段测试即剔除 |

## 对本项目的可执行来源策略

1. **候选层**：接入 `iptv-org`、`vbskycn`、`fanmingming`、`suxuang`、`YueChan`、`ChinaIPTV`，同时维护官方频道页索引；记录来源仓库、原始 URL、最终重定向 Host、首次/最后成功时间。
2. **信任层**：官方域名/明确 CDN 加分；个人 IP/PHP 中转、跨境不明 CDN、校园网、公开组播网关大幅降权或直接拒绝。不要仅凭频道名判断“国内源”。
3. **探测层**：从中国大陆至少移动/联通/电信三个探针测 DNS、TCP/TLS、主清单、变体清单和连续 3–5 个媒体段；记录首帧、平均吞吐、卡顿、分辨率、帧率、音视频编码。GitHub Actions 海外探针只能检查语法/基本存活，不能代表国内流畅度。
4. **时效层**：候选每 6 小时轻量探活、每天完整测速；连续两次失败降级，三次失败下架；成功恢复两次再回归。临时签名地址不写入仓库。
5. **输出层**：至少拆成 `china.m3u8`（多运营商公网验证）、`china-ipv6.m3u8`、`operator/<省>-<运营商>.m3u8`。每个频道保留 2–3 条不同 Host 的健康线路，而不是同一故障域的重复 URL。
6. **合规层**：公共仓库只发布确认允许链接/再分发的源；其余提供官方观看页。收到权利人通知应能按来源和频道快速删除。若要代理/转码/推流，必须先取得明确授权；Guovin 项目本身也明确提醒中国大陆内容授权、备案和许可要求（[免责声明](https://github.com/Guovin/iptv-api#%E5%85%8D%E8%B4%A3%E5%A3%B0%E6%98%8E)）。

## 推荐优先级

- **P0（元数据/官方观看）**：央视网、央视频、各省台官方直播页；可靠但通常不允许抽取后公开再分发。
- **P1（候选发现）**：`iptv-org/countries/cn.m3u`、官方域名 HLS、CGTN 公网流；经过授权和多点验证后才发布。
- **P2（工程与交叉验证）**：Guovin 的测速/过滤框架，以及 vbskycn、fanmingming、myIPTV、YueChan、ChinaIPTV 的候选清单。
- **拒绝默认纳入**：个人 PHP/API 中转、裸云主机 IP、校园 IPTV、公开组播反代、过期签名、无法确定最终 Host 或声称 4K/8K 却未实测的地址。

最终判断：**“抓得更多”无法保障质量；只有在目标用户所在的中国大陆网络持续实测，并把公网、IPv6 和运营商专网分开，才能显著降低不可播放率。** 对官方内容，稳定性最高的方案仍是跳转/嵌入获准的官方播放器，而不是公开固定媒体地址。
